# 开发计划

## 里程碑计划

| 里程碑 | 目标 | 交付物 | 状态 |
|--------|------|--------|------|
| M0 | 工程骨架搭建 | 可编译的空 App + 目录结构 + 立项文档 | ✅ 完成 |
| M1 | 数据模型与源规范 | 统一中间模型、SourceAdapter 接口、JSON/JS 源规范 | ✅ 完成 |
| M2 | 源解析引擎 | JsonLoader/Parser、JsLoader/Parser、Rhino 集成、SourceManager | ✅ 完成 |
| M3 | 网络与数据层 | HttpClient、Room 数据库、Repository、DataStore | ✅ 完成 |
| M4 | 小说模块 | 搜索/目录/阅读 UI + 字体/背景/日夜间设置 | ✅ 完成 |
| M5 | 漫画模块 | 搜索/阅读 UI + 图片适配 + 翻页方式 | ✅ 完成 |
| M6 | 视频模块 | 搜索/目录/播放 UI + Media3 集成 | ✅ 完成 |
| M7 | 通用页面与集成收尾 | 源管理/书架/设置页 + 导航接入 + 编译一致性 | ✅ 完成 |
| M8 | 增强 | 文件导入/进度恢复/防盗链/继续阅读 + 构建指南 | ✅ 完成 |

## 详细任务拆解

### M1 数据模型与源规范（下一步）
- [ ] 定义 `SourceType` 枚举（NOVEL / COMIC / VIDEO）
- [ ] 定义 `SourceInfo`（源元信息）
- [ ] 定义 `MediaItem`、`ChapterItem`、`ContentResult` 中间模型
- [ ] 定义 `SourceAdapter` 接口
- [ ] 定义 `SearchResult`、`ContentResult` 封装

### M2 源解析引擎
- [ ] Rhino 集成与初始化（SourceJsEngine）
- [ ] JsonSourceLoader / JsonSourceParser
- [ ] JsSourceLoader / JsSourceParser
- [ ] 内置辅助函数注入（fetch / parseHtml / log）
- [ ] SourceManager（源注册、查找、调度）

### M3 网络与数据层
- [ ] HttpClient 封装（OkHttp）
- [ ] Room 实体（SourceEntity、BookEntity、ProgressEntity）
- [ ] DAO 定义
- [ ] Repository 实现
- [ ] DataStore 偏好设置封装

### M4 小说模块
- [ ] 小说搜索页
- [ ] 小说详情 + 目录页
- [ ] 阅读页（正文渲染）
- [ ] 字体大小调节
- [ ] 背景颜色 + 日夜间模式

### M5 漫画模块
- [ ] 漫画搜索页
- [ ] 章节列表页
- [ ] 图片阅读页（屏幕适配）

### M6 视频模块
- [ ] 视频搜索页
