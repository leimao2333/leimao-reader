# M9 阶段：阅读体验打磨 + 版本信息同步 + 本机构建环境

> 日期：2026-10-11

## 一、阶段目标

在 v1.0.0.6 基础上，修复版本信息不同步问题，落地两项文档遗留的阅读体验项，
并在本机（E 盘）从零搭建可用的 Android 构建环境，完成编译与真机验证。

## 二、本阶段完成内容

### 1. 修复版本信息不同步

- **问题**：`AppVersion.CURRENT_VERSION` 长期停留在 `"1.0.0.1"`，而 `build.gradle.kts`
  已迭代到 `1.0.0.6`。导致设置页「当前版本」与更新日志页显示的都是旧版本。
- **修复**：
  - `AppVersion.CURRENT_VERSION` 提升至当前版本，并补全 v1.0.0.2 ~ v1.0.0.6 的全部更新日志条目
  - `build.gradle.kts` 版本号同步提升（versionCode / versionName）
  - 仓库根 `CHANGELOG.md` 追加对应版本记录

### 2. 小说滚动阅读记住正文位置

- 复用 `ProgressEntity.textPosition` 字段（此前已存在但从未使用），以 **比例 0~10000** 记录正文位置。
- `NovelReaderViewModel`：
  - 新增 `initialTextPosition`（进入时的恢复比例）与内部 `lastTextPosition`
  - `init` 时读取历史进度：若进度所属章节正是本次进入的章节，则恢复其正文位置
  - 新增 `saveScrollRatio(chapterIndex, ratio)`：带章节校验，避免切换章节瞬间串章
  - `loadContent`（切章）会重置位置到顶部
- `NovelReaderScreen.ScrollNovel`：
  - 滚动状态按章节 key（`remember(chapterIndex)`），**修复切换章节仍停留在上一章位置的旧 bug**
  - 进入时按记录比例恢复；滚动停止约 400ms 后回写（`collectLatest` 天然去抖）

### 3. 漫画图片预加载 + 加载失败重试

- 新增图片预加载：进入章节预热前 4 张；上下滚动时预加载后续 2 张；左右翻页时预加载相邻页。
- `ComicImage` 改用 `SubcomposeAsyncImage`：
  - 加载中显示圆形进度占位
  - 加载失败显示占位图标 + 「点击重试」（重试计数并入缓存键，触发全新请求）

### 4. 左右翻页正文切章回到第一页

- `HorizontalPagerNovel` 增加切章重置逻辑，避免沿用上一章页码。

### 5. 清理过时注释

- 移除 `SourceJsEngine` / `PlaceholderEngine` 中 M2 时期残留的 `TODO(M2)` 注释
  （相关能力早已由 `SourceJsBridge` 与 `HtmlSelectorEngine` 实现）。

### 6. 本机（E 盘）Android 构建环境

在本机（此前无任何 Android 环境）自建完整工具链，全部落在 `E:/android-dev`：

| 组件 | 路径 | 来源 |
|------|------|------|
| JDK 17 (Temurin) | `E:/android-dev/jdk-17.0.20.1+1` | 清华 Adoptium 镜像 |
| Gradle 8.7 | `E:/android-dev/gradle-8.7` | 腾讯云 Gradle 镜像 |
| Android SDK | `E:/android-dev/sdk` | Google（经本地代理下载） |
| Gradle 缓存 | `E:/android-dev/gradle-home` | — |

- SDK 组件：`platform-tools`、`platforms;android-35`、`build-tools;35.0.0`
- `local.properties` 指向 `E:/android-dev/sdk`

**构建命令**：
```bash
cd /e/work/app/NovelReader
JAVA_HOME="E:/android-dev/jdk-17.0.20.1+1" \
GRADLE_USER_HOME="E:/android-dev/gradle-home" \
/e/android-dev/gradle-8.7/bin/gradle assembleDebug --no-daemon
```
