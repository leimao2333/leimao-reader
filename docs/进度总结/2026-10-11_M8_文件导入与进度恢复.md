# M8 增强阶段：文件导入、进度恢复、防盗链、继续阅读

> 日期：2026-10-11

## 一、阶段目标

在 M0~M7 完整框架基础上，补齐三项最影响实际可用性的增强，并输出构建运行指南。

## 二、本阶段完成内容

### 1. 接入系统文件选择器导入源

- `SourceImportScreen` 接入 `ActivityResultContracts.OpenDocument`（SAF）
- 支持从本地选择 `.json` / `.js` 文件，自动读取内容并回填文件名与源码
- 通过 `OpenableColumns.DISPLAY_NAME` 查询文件名，用于格式识别
- 保留原有「粘贴源码」方式，两种方式并存

### 2. 视频播放进度恢复 + 防盗链请求头接入

- `VideoPlayerViewModel` 重写：
  - **防盗链**：通过 `DefaultHttpDataSource.Factory.setDefaultRequestProperties(headers)` 将 `ContentResult.videoHeaders` 注入 Media3，再经 `DefaultMediaSourceFactory` 应用
  - **进度恢复**：首次进入（`init`）时读取 `ProgressRepository` 进度，若进度对应当前集且 `playPositionMs > 0`，则 `seekTo` 到上次位置
  - 切换选集不恢复（`restoreProgress = false`），避免跨集误 seek
- 添加 `@UnstableApi` 标注（Media3 的 `setMediaSourceFactory` 为实验 API）

### 3. 书架继续阅读直达进度

- `BookShelfViewModel` 注入 `ContentRepository`，新增 `continueReading(item, onReady)`
- 点击书架条目 → 加载章节列表 + 进度 → 定位进度章节（按 `chapterUrl`，回退按 `chapterIndex`）
- 有进度章节 → 直达阅读页/播放页；无章节/无进度 → 回详情页
- 小说/漫画/视频三类统一处理

### 4. 构建运行指南

- 新增 `docs/构建运行指南.md`，包含环境要求、构建步骤、依赖清单、首次运行体验、常见问题（FAQ）、真机调试要点、发布检查清单
