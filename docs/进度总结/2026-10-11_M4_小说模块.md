# 进度总结 — M4 小说模块

> 日期：2026-10-11

## 一、本阶段完成内容

### 1. ViewModel 层（3 个）
- `NovelSearchViewModel` — 搜索关键词、结果列表、加载/错误状态
- `NovelDetailViewModel` — 详情 + 章节列表 + 收藏状态（并行加载）
- `NovelReaderViewModel` — 正文内容、章节切换、阅读设置、进度保存
  - 字体大小 / 背景色 / 日夜间模式均通过 PreferencesManager 持久化

### 2. UI 层（3 个页面）
- `NovelSearchScreen` — 搜索框 + 结果列表（复用 SearchBar + MediaItemCard）
- `NovelDetailScreen` — 封面/标题/作者/简介 + 收藏按钮 + 章节列表
- `NovelReaderScreen` — 正文渲染 + 设置面板 + 上一章/下一章
  - **字体大小调节**（A- / A+，7 档）
  - **背景颜色切换**（白天 4 色 / 夜间 3 色）
  - **日/夜间模式切换**
  - 点击正文呼出设置面板

### 3. 导航接入
- `NavArgs` — MediaItem / ChapterItem 的 JSON 编解码（导航参数传递）
- `Routes` — 更新为编码对象参数的路由
- `AppNavHost` — 接入小说完整链路：搜索 → 详情 → 阅读
- `NovelViewModelFactory` — 通用 ViewModel 工厂（从 AppContainer 构建）

### 4. 组件改进
- `SearchBar` — 搜索按钮可点击 + 键盘回车触发搜索

### 5. MainActivity 接入
- 从 `NovelReaderApp.container` 获取依赖容器，传入导航图
