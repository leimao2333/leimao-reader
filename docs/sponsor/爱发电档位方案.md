## 0. 先定一件事：月付档位，还是「一次性发电」

这两个词在爱发电里是**两套东西**，填错会让粉丝误会，必须先选：

| | 赞助方案（档位） | 一次性发电 |
|---|---|---|
| 入口 | 主页「赞助方案」列表里的卡片 | 主页的「发电」按钮 |
| 金额 | 你定死的（¥5 / ¥10） | 粉丝自己填，也能选你设的推荐额 |
| 周期 | 显示为**每月** | 一次付清，不重复 |
| 手续费 | 一样 | 一样 |
| 适合 | 想要「每月固定一点点」的长期支持 | 就是想请你喝瓶水 |

**建议：两个都做，但主力放「一次性发电」。**

理由很直白：你这应用是一次性交付的东西，粉丝没有「每月续费」的心理预期。
挂「每月 ¥5」的结果是有人点进来发现是订阅，直接退出去。
一次性发电没有这个摩擦，还剩一道「金额自选」——有人想给 20 也随他。

做法：在「发电」入口的推荐金额里填 `5 / 10 / 20`，把两张图放在主页介绍里，
配一句「两瓶快乐水 5 块，一个汉堡 10 块」。档位卡片当作**补充**放着，不指望它是主入口。

> 如果你决定只做档位、不做一次性发电，下面两套文案可以直接用，只需把金额单位理解成「每月」。

## 4. 三条红线（别踩）

1. **档位权益里不写「赞助后可用的功能 / 内容」**
   写了就从「赞赏」变成「付费商品」，性质变了：要兑现、要退款、要开票，
   而且和你 README 里「不影响任何功能」的承诺直接打架。
   权益永远只写「感谢」两个字级别的回馈。

2. **不在档位里承诺更新频率**
   「每月至少更 4 个源」这种话一旦写上就是义务。个人项目，别给自己上枷锁。

3. **不写「赞助后拉你进源分享群」**
   这条最要命——把自己的收款和「分发侵权源」绑在一起。赞赏就是赞赏，别混。

## 5. 后台怎么填（操作顺序）

1. 爱发电 → 创作中心 → **赞助方案** → 新建；
2. 档位名、金额照上面填，周期按第 0 节的决定选；
3. **上传配图**（两张图分别对应）；
4. 详细介绍粘进正文，注意保留空行，爱发电正文不认 Markdown 的加粗，别写 `**`；
5. 权益留空或写「感谢署名」；
6. 保存后**用手机点一次自己的主页**，确认卡片和图都正常显示、点「发电」能进付款页。

第 6 步别省。爱发电是前端渲染，PC 上看着正常、手机上错位的情况很常见。
