# 进度总结 — M6 视频模块

> 日期：2026-10-11

## 一、本阶段完成内容

### 1. ViewModel 层（3 个）
- `VideoSearchViewModel` — 搜索状态
- `VideoDetailViewModel` — 详情 + 视频目录（选集）
- `VideoPlayerViewModel` — Media3 ExoPlayer 管理 + 播放状态 + 进度

### 2. UI 层（3 个页面）
- `VideoSearchScreen` — 搜索 + 结果列表
- `VideoDetailScreen` — 封面/标题/收藏 + **视频目录（选集列表）**
- `VideoPlayerScreen` — **Media3 ExoPlayer 播放** + 选集切换

### 3. 核心需求落实

**视频目录（选集）**：
- 详情页展示完整选集列表
- 播放页下方也有选集列表，点击切换，当前集高亮

**视频播放（Media3 ExoPlayer）**：
- 16:9 播放器区域
- 内置播放控制条（play/pause/进度/全屏）
- 播放地址从源解析（支持防盗链请求头预留）

**播放进度记录**：
- 切换选集时保存进度
- 退出播放页时保存进度（onDispose + onCleared）

### 4. 导航接入
- `Routes` 新增 videoDetail / videoPlayer 构建函数
- `AppNavHost` 接入视频完整链路（搜索 → 详情 → 播放）
