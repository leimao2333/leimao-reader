# 需求分析文档

## 一、源规范（Source Spec）

统一的源规范是三类内容共用的基础。一个"源"（Source）由以下要素构成：

### 1.1 源元信息
```
- name: 源名称
- type: novel | comic | video  （内容类型）
- version: 源版本号
- author: 源作者
- desc: 源描述
- baseUrl: 源基础地址
```

### 1.2 源能力（Capabilities）
每个源必须实现以下能力，通过 JSON 字段或 JS 函数暴露：

| 能力 | 小说 | 漫画 | 视频 |
|------|------|------|------|
| search（搜索） | ✅ | ✅ | ✅ |
| catalog（分类/发现） | ✅ | ✅ | ✅ |
| detail（详情） | ✅ | ✅ | ✅ |
| chapterList（目录/章节） | ✅ | ✅ | ✅ |
| content（正文/图片/播放地址） | ✅ | ✅ | ✅ |

### 1.3 数据中间模型（统一格式）
无论源是 JSON 还是 JS，解析后统一映射到以下中间模型：

```kotlin
// 搜索/发现结果项
data class MediaItem(
    id: String,          // 唯一ID
    title: String,       // 标题
    cover: String?,      // 封面
    author: String?,     // 作者/up主
    desc: String?,       // 简介
    type: SourceType     // 类型
)

// 章节/目录项
data class ChapterItem(
    id: String,
    title: String,
    url: String          // 章节内容地址
)

// 正文内容（小说文本 / 漫画图片列表 / 视频播放地址）
data class ContentResult(
    novelText: String?,
    comicImages: List<String>?,
    videoUrl: String?
)
```

## 二、JSON 源格式定义

```json
{
  "name": "示例小说源",
  "type": "novel",
  "version": "1.0.0",
  "baseUrl": "https://example.com",
  "search": {
    "url": "https://example.com/search?keyword={{keyword}}&page={{page}}",
    "method": "GET",
    "list": "div.book-item",
    "fields": {
      "id": "a@href",
      "title": ".title@text",
      "cover": "img@src",
      "author": ".author@text"
    }
  },
  "detail": {
    "url": "{{itemUrl}}",
    "fields": { "desc": ".desc@text", "cover": ".cover img@src" }
  },
  "chapterList": {
    "url": "{{detailUrl}}",
    "list": "div.chapter a",
    "fields": { "id": "@href", "title": "@text" }
  },
  "content": {
    "url": "{{chapterUrl}}",
    "text": "#content@html"
  }
}
```

**字段说明**：`{{keyword}}`、`{{page}}`、`{{itemUrl}}` 等为占位符；`@href`、`@text`、`@html`、`@src` 为属性提取符；CSS 选择器用于定位元素。

## 三、JS 源格式定义

JS 源兼容 legado/阅读 的书写习惯，暴露全局对象或函数：

```javascript
// 返回源元信息
function getMeta() {
  return { name: "示例JS源", type: "novel", version: "1.0" };
}

// 搜索
function search(keyword, page) {
  // 使用内置网络函数请求并解析
  var html = fetch("https://example.com/search?q=" + keyword);
  var doc = parseHtml(html);
  // ... 解析逻辑
  return [ { id: "...", title: "...", cover: "...", author: "..." } ];
}

// 目录
function chapterList(itemUrl) { ... }
// 正文
function content(chapterUrl) { ... }
```

**内置辅助函数**（由 Rhino 引擎注入）：
- `fetch(url, options)` — 网络请求
- `parseHtml(html)` — HTML 解析（返回类 DOM 对象）
- `log(msg)` — 日志输出

## 四、非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | 漫画图片懒加载、预加载；小说分章缓存 |
| 体验 | 阅读进度自动保存；深色模式全App适配 |
| 扩展性 | 源适配器接口 + 解析引擎插件化 |
| 兼容性 | minSdk 24（Android 7.0+） |
