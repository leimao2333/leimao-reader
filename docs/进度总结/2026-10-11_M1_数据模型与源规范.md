# 进度总结 — M1 数据模型与源规范完善

> 日期：2026-10-11

## 一、本阶段完成内容

### 1. JSON 源规范样例（3 份）
- `samples/json/novel_sample.json` — 小说源
- `samples/json/comic_sample.json` — 漫画源
- `samples/json/video_sample.json` — 视频源

每份样例完整展示 `search / detail / chapterList / content` 四类规则的写法，
以及三类内容在正文提取上的差异（小说用 `text`、漫画用 `images`、视频用 `videoUrl` + 防盗链 `headers`）。

### 2. JS 源规范样例（3 份）
- `samples/js/novel_sample.js` — 小说源
- `samples/js/comic_sample.js` — 漫画源
- `samples/js/video_sample.js` — 视频源

每份样例暴露 `getMeta / search / detail / chapterList / content` 五个函数，
兼容 legado/阅读 的书写习惯，使用内置 `fetch` / `parseHtml` 辅助函数。

### 3. 源导入校验规则（SourceValidator）
`source/loader/SourceValidator.kt`，实现：
- 内容非空、格式识别（按扩展名 + 内容特征判断 JSON / JS）
- JSON 源：校验 name、type 合法性、search 规则存在性
- JS 源：校验必需函数（getMeta / search / chapterList / content）

### 4. 源引擎骨架完善
- `JsonRuleSet.kt` — JSON 源规则数据模型（Rule / RuleSet）
- `JsonRuleParser.kt` — JSON 源文本 → 结构化规则集的解析器（已实现）
- `HtmlSelectorEngine.kt` — 选择器提取表达式引擎（表达式解析已实现，HTML 解析待 M2 引入 jsoup）
