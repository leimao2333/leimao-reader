# 小说 / 漫画 / 视频 板块待办清单

> 生成于 v1.3.8.0（2026-10-13）。基于当前代码真实状态梳理，非历史遗留清单。
> 优先级：P0 = 明显缺口 / 影响核心体验；P1 = 重要体验；P2 = 可选优化。
> 说明：项目已迭代到 v1.3.8.0，早期《小说模块问题清单》《开发计划》中的大多数 P0 项
> 早已落地（三区点击、翻页记页码、最近阅读封面、TTS 朗读、书签、换源、离线缓存等），
> 本表只列**当前仍未做**的事项。

## 一、小说模块

现状：功能已较完整 —— 三区点击翻页、精确分页（TextLayoutResult）、翻页记页码、书签、
换源、离线缓存、TTS 朗读、简繁转换、亮度调节、正文净化/替换规则、音量键翻页、自动翻页、
章内/全文搜索、最近阅读（冗余存书名 + 相对时间 + 长按移除）均已实现。

| # | 待办事项 | 现状与目标 | 优先级 |
|---|---------|-----------|-------|
| N1 | 阅读历史独立页 | 只有首页「最近阅读」；目标：独立「历史」页，按类型/时间筛选，可批量清除 | P2 |
| N2 | 作者可点击 | 详情页作者不可点；目标：点击作者搜索其全部作品 | P2 |
| N3 | 换源精确定位 | 换源按章节名匹配，失败回第一章；目标：匹配失败时给提示并尝试按序号定位 | P2 |
| N4 | 全书下载进度 / 断点续传 | 现有整本缓存，但缺明细进度页与断点续传提示 | P2 |

## 二、漫画模块

现状：两种翻页方式（上下滚动 / 左右翻页）、三区点击、图片预加载、加密图解密与乱序还原、
离线缓存（全书/前 N 话/进度后 N 话）、封面防盗链均已实现。

| # | 待办事项 | 现状与目标 | 优先级 |
|---|---------|-----------|-------|
| C1 | 双指缩放 | 图片仅按宽度适配（ContentScale.FillWidth），无缩放；目标：双指捏合缩放 / 双击放大，可拖动查看细节 | P1 |
| C2 | 亮度 / 音量调节 | 无亮度、音量手势；目标：对标主流漫画 App，竖滑左调亮度右调音量 | P1 |
| C3 | 方向锁定 / 横屏 | 无横屏阅读与方向锁定；目标：支持横屏双页 / 单页，锁定屏幕方向 | P2 |
| C4 | 目录分卷展示 | 目录扁平排列；目标：legado 源按「卷」分组（第一卷/第二卷） | P2 |
| C5 | 预加载策略可调 | 预加载固定张数；目标：设置页可调预加载数量与是否仅在 WiFi 下预加载 | P2 |

## 三、视频模块

现状：已对标 MoonTV 完成大部分 —— 影视首页多分区、继续观看、片库四维筛选（分类/地区/年份/排序）、
播放页选集/换源双 Tab、线路测速择优、搜索聚合折叠、全屏/倍速/手势/连播、视频详情信息补全均已实现。

| # | 待办事项 | 现状与目标 | 优先级 |
|---|---------|-----------|-------|
| V1 | 字幕 / 投屏 | 播放器无字幕、投屏能力；目标：外挂字幕加载、DLNA/Chromecast 投屏 | P2 |
| V2 | 画中画（PIP） | 无小窗播放；目标：切后台时小窗继续播放 | P2 |
| V3 | 播放记录云端同步 | 播放进度仅本地；目标：随 WebDav 云备份一并同步播放记录（当前备份已含进度，但缺「播放记录页」） | P2 |
| V4 | 弹幕 | 无弹幕（采集站一般无弹幕接口，属可选增强） | P2 |

---

## 优先级总览（按投入产出排序）

1. **C1 双指缩放 + C2 亮度/音量**（P1）— 漫画阅读器与主流体验差距最大的两项，改动集中、见效快。
2. 其余 P2 项按需排期。
