# M7 收尾阶段：通用页面与集成收尾

> 日期：2026-10-11

## 一、阶段目标

补齐源管理、书架、设置三大通用页面，完善首页导航，接入全部剩余路由，使 App 形成完整闭环（导入源 → 搜索 → 详情 → 阅读/播放 → 收藏 → 进度），并修正编译层面的接口一致性问题。

## 二、本阶段完成内容

### 1. 源管理页（App 闭环关键入口）

| 文件 | 职责 |
|------|------|
| `SourceManageViewModel.kt` | 源列表、导入、删除、启停，响应式观察 |
| `SourceManageScreen.kt` | 源列表（名称/类型/版本/作者 + 启停开关 + 删除）、空状态引导、FAB 导入入口 |
| `SourceImportScreen.kt` | 粘贴源源码 + 可选文件名，导入 JSON/JS 源 |

- 支持 JSON / JS 源导入（`SourceValidator` 自动识别格式并校验）
- 源启用/禁用状态持久化（Room）
- 导入成功/失败通过 Snackbar 提示

### 2. 书架页

| 文件 | 职责 |
|------|------|
| `BookShelfViewModel.kt` | 收藏列表 + 每条进度加载 |
| `BookShelfScreen.kt` | 收藏内容展示（封面/标题/类型/进度），点击回详情，移除 |

- 小说/漫画/视频三类收藏统一展示
- 展示最近阅读进度（章节标题）
- 点击按类型跳转到对应详情页

### 3. 设置中心

| 文件 | 职责 |
|------|------|
| `SettingsViewModel.kt` | 全局设置状态管理（DataStore） |
| `SettingsScreen.kt` | 日夜间模式、小说字体/背景、漫画翻页方式 |

- **夜间模式**：全局主题切换（与 MainActivity 联动）
- **小说字体大小**：14~26 档位滑动调节
- **小说背景色**：4 种白天配色可选
- **漫画翻页方式**：上下滚动 / 左右翻页切换

### 4. 首页导航完善

`HomeScreen.kt` 重写为卡片式布局：
- 上半区「开始阅读」：小说 / 漫画 / 视频（三列卡片）
- 下半区「我的」：书架 / 源管理 / 设置（三列卡片）

### 5. 导航与主题接入

- `AppNavHost.kt` 完整接入：书架、源管理、源导入、设置路由（此前仅有三大内容模块）
- `MainActivity.kt` 主题接入 DataStore 的 `darkThemeFlow`，日夜间模式实时生效

### 6. 编译一致性修复

- 修复 `SourceRepository.getAdapter()` 接口返回类型不一致（接口声明 `SourceAdapter`，实现返回 `SourceAdapter?`，统一为可空返回）

## 三、遗留事项 / 风险

1. **编译验证需在 Android Studio 完成**（Compose / Room kapt / Rhino / Media3 全套依赖的实际编译）
2. **源导入仅支持粘贴源码**，尚未接入系统文件选择器（SAF），从文件导入需后续补 `ActivityResultContracts.OpenDocument`
3. **视频播放进度仅保存、未恢复**（进入播放页未 seek 到上次位置）
4. **视频防盗链请求头未接入 Media3**（需自定义 `DataSource.Factory`）
5. **书架「继续阅读」** 目前点击回详情页，未直接跳转到上次章节/进度位置
6. 阅读页正文内滚动位置未保存（仅保存章节级进度）
