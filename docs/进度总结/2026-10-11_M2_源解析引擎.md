# 进度总结 — M2 源解析引擎

> 日期：2026-10-11

## 一、本阶段完成内容

### 1. HtmlSelectorEngine（选择器解析引擎，基于 jsoup）
`source/engine/HtmlSelectorEngine.kt`，实现：
- `extract(html, expr)` — 提取单个值（支持 `selector@text/@html/@href/@src`）
- `extractList(html, listSelector, fields)` — 提取列表（支持相对选择器）
- `removeElements` — 正文净化（移除广告/脚本）
- `toAbsoluteUrl` — 相对 URL 转绝对 URL
- 额外支持 `data-src` / `data-original`（漫画懒加载图片）

### 2. JsonSourceAdapter（JSON 源适配器）
`source/parser/JsonSourceAdapter.kt`，基于规则集实现：
- search / detail / chapterList / content 完整逻辑
- 占位符替换 + HTTP 请求 + 选择器提取
- 三类内容正文差异化处理（小说 text / 漫画 images / 视频 videoUrl + headers）
- 相对路径自动转绝对路径

### 3. JSON 源加载/解析
- `JsonSourceLoader` — JSON 源文本 → SourceInfo
- `JsonSourceParser` — JSON 源文本 → JsonSourceAdapter

### 4. JS 源加载/解析（Rhino）
- `SourceJsBridge` — 内置函数注入（fetch / parseHtml / log）
- `JsDocument` / `JsElement` — 封装 jsoup，提供 querySelector / querySelectorAll / text / html / getAttribute
- `JsSourceAdapter` — 执行 JS 函数，返回值转统一中间模型
- `JsSourceLoader` / `JsSourceParser` — 独立作用域执行

### 5. SourceManager 完整链路
打通「校验 → 加载 → 解析 → 适配器」完整流程：
```
importSource(rawContent, fileName)
  → SourceValidator.validate
  → SourceLoader.load (SourceInfo)
  → SourceParser.createAdapter (SourceAdapter)
  → 注册 + 缓存
```

### 6. Data 层仓库实现
- `SourceRepositoryImpl` — 基于 SourceManager
- `ContentRepositoryImpl` — 跨源聚合搜索（单源失败不影响整体）

### 7. 数据模型修复
- `ChapterItem` 新增 `sourceId` 字段（修复正文获取时源定位的缺口）

### 8. 单元测试
`SourceEngineTest` — 覆盖占位符替换、表达式解析、单值提取、列表提取、JSON 规则解析。
