# 进度总结 — M3 网络与数据层

> 日期：2026-10-11

## 一、本阶段完成内容

### 1. Room 数据库（三张表）
- `SourceEntity` — 源持久化（含原始内容 rawContent，用于重启恢复）
- `BookEntity` — 书架/收藏
- `ProgressEntity` — 阅读/播放进度（支持小说字符偏移 + 视频播放毫秒）
- 对应 `SourceDao` / `BookDao` / `ProgressDao`，提供响应式 Flow 查询
- `AppDatabase` — 数据库定义（version 1）

### 2. 源持久化
`SourceRepositoryImpl` 改造完成：
- 源导入 → 写数据库 + 注册 SourceManager
- 源删除 / 启停 → 同步数据库
- `restoreSources()` — App 启动时从数据库恢复源
- `observeSources()` — 响应式观察源列表

### 3. 书架与进度持久化
- `BookRepository` / `BookRepositoryImpl` — 书架增删查（响应式 Flow）
- `ProgressRepository` / `ProgressRepositoryImpl` — 进度保存/读取
- 新增 Domain 层接口 + `ReadingProgress` 模型

### 4. HttpClient 完善
- **字符集识别**：Content-Type → HTML meta → 乱码检测 → GBK 回退
- **Cookie 持久化**：内存 CookieJar，会话内跨请求共享
- **请求重试**：网络错误 + 5xx 自动重试（最多 2 次）
- **gzip**：显式声明 Accept-Encoding

### 5. 依赖注入容器
`AppContainer` — 简易手动 DI，统一管理：
- 数据库、偏好设置、源管理器
- 四个仓库（source / content / book / progress）
- `NovelReaderApp` 初始化容器 + 后台恢复源
