# 项目立项书

## 一、项目概述

**项目名称**：阅读神器（NovelReader）

**项目定位**：一款支持自定义导入书源的聚合类阅读 App，统一支持**小说、漫画、视频**三大内容形态的在线阅读。

**核心价值**：
- 用户可自由导入网络上的书源（JSON / JS 两种格式），实现内容自主、生态开放。
- 三大内容形态统一管理，一套 App 满足阅读、看漫、看视频的全部需求。
- 高度可定制（字体、背景、翻页方式、日夜间模式）。

## 二、项目目标

| 目标项 | 说明 |
|--------|------|
| 内容形态 | 小说 / 漫画 / 视频 三类源统一支持 |
| 源格式 | JSON 源 + JS 源（两类均可导入） |
| 阅读体验 | 小说可调字体大小、背景色（白天/夜间）；漫画完美适配屏幕、可调翻页方式；视频支持目录 |
| 搜索能力 | 三类源均支持站内搜索 |
| 工程可维护性 | 模块化、分层清晰、预留扩展冗余空间 |

## 三、技术选型

| 维度 | 选型 | 理由 |
|------|------|------|
| 语言 | Kotlin | 安卓官方首选，简洁安全 |
| UI | Jetpack Compose | 声明式UI，阅读器类App开发效率高 |
| 架构 | MVVM + 分层（Data/Domain/UI） | 职责清晰，易扩展 |
| JS 引擎 | Rhino 1.7.15 | 纯Java实现，兼容 legado/阅读 等开源阅读器 JS 源 |
| 网络 | OkHttp + Retrofit | 稳定成熟的网络栈 |
| 数据库 | Room | 本地书源/书架/历史持久化 |
| 图片 | Coil | 漫画图片加载 |
| 视频 | Media3 (ExoPlayer) | 官方推荐视频播放 |
| 偏好设置 | DataStore | 字体/背景/翻页等设置持久化 |

## 六、风险与应对

| 风险 | 应对 |
|------|------|
| JS 源格式多样 | 制定统一中间格式，解析引擎做兼容适配层 |
| 漫画图片加载性能 | Coil 缓存 + 懒加载 + 预加载 |
| 视频源防盗链 | 解析真实播放地址，可配置自定义请求头 |
| 兼容不同书源规范 | 预留"源适配器"接口，可按需扩展 |
