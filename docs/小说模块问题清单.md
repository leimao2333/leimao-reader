# 小说模块问题清单（改进表单）

> 参考主流小说 App（阅读/legado、起点、番茄、微信读书、七猫）交互标准梳理。
> 优先级：P0 = 严重/反人类，必须改；P1 = 重要体验，建议改；P2 = 可选优化。

## 一、阅读页手势与菜单（用户重点反馈）

| # | 现状问题 | 应有行为（参考主流 App） | 优先级 |
|---|---------|------------------------|-------|
| 1 | 单击屏幕任意位置都弹/收菜单，**没有「左翻页 / 右翻页」手势** | 三区点击：左 1/3 单击=上一页/上一章，右 1/3 单击=下一页，中间 1/3 单击=呼出菜单 | **P0** |
| 2 | 菜单呼出/收起逻辑反人类：阅读时随手一点就误弹菜单，打断阅读 | 单击中间才呼出菜单；再次单击中间或点击顶部返回键收起；点菜单外空白也可收起 | **P0** |
| 3 | 滚动模式只能手指滑动，**无单击翻页** | 滚动模式支持「单击下半屏=向下翻、上半屏=向上翻」（可开关） | P0 |
| 4 | 翻页模式下滑到章末靠引导页续章（已修），但**单页内容由字符数粗估**，中英混排/标点会截断不齐 | 按真实排版分页（TextLayoutResult 精确测量每页断行位置） | P1 |
| 5 | 无「双击呼出菜单」「长按选择/复制文字」手势 | 双击中央呼出菜单；长按弹出文本选择/复制 | P2 |

---

### 修复顺序建议（按影响面排序）
1. **P0 阅读手势与菜单**（#1、#2、#3、#32）：单击左右翻页 + 中间呼菜单 + 翻页进度记忆 —— 直接决定阅读体验
2. **P0 搜索元数据**（#23）：搜索结果显示章节数/字数/状态 —— 决定「找书」体验
3. **P0 最近阅读封面/书名**（#12）：进度表冗余存封面
4. **P1 书架重做**（#16–#18）：封面墙 + 进度 + 最近阅读排序 + 多选
5. **P1 阅读设置补齐**（#6、#7）：行距/页边距/字体/自动翻页
6. **P1 详情页元信息**（#27）
7. **P2 其余**
