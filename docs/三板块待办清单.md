## 三、视频模块

现状：已对标 MoonTV 并超越 —— 影视首页**聚合式源**（自动探测存活源、合并分类、跨源去重，死源跳过）、
短剧**红果式竖屏沉浸播放**（海报直进竖屏全屏 + 红果选集浮层 + 竖横屏切换）、视频清晰度调节（HLS 多码率轨道）、
片库四维筛选、播放页选集/换源双 Tab、线路测速择优、搜索聚合折叠、全屏/倍速/手势/连播、视频详情信息补全均已实现。
发现页已移除（与首页聚合浏览重合）。

> v1.4.6.0 已落地：**外挂字幕加载**（V1 字幕部分：SAF 选本地 srt/vtt/ass/ssa → side-loaded 字幕轨道 +
> 开关/移除）、**画中画 PIP**（V2：播放中切后台自动小窗，回前台恢复，Android 8.0+）。
> **V3 播放记录云端同步**：WebDav 备份自 v1.3.8.0 起已含 `progress` 表（视频播放位置 playPositionMs/durationMs），
> 「播放记录页」由 v1.4.4.0 的「阅读历史」页覆盖（含视频类型筛选 + 点击续播），无实质缺口，视为已完成。
